✅ Fonksiyonel Özellikler

  • ✓ Admin / Öğrenci rol ayrımı ve yetkilendirme
  • ✓ JWT tabanlı kimlik doğrulama
  • ✓ Admin: Sınav oluşturma, soru ekleme, süre belirleme
  • ✓ Öğrenci: Aktif sınavları görme, sınava katılma
  • ✓ Süreli sınav sistemi (geri sayım)
  • ✓ Süre dolduğunda otomatik bitirme
  • ✓ Otomatik puanlama sistemi
  • ✓ Aynı sınava tekrar girme engeli
  • ✓ Detaylı sonuç ekranı (not dönüşümü ile)
